# 获取网盘音乐完整详情 (管理后台)

获取单条网盘曲目的完整管理端详情，包括所有者信息、物理音频资产、关联封面/歌词资产和审计字段。

- **请求方法**：`GET`
- **请求路径**：`/api/admin/cloud-music/:uuid`
- **需要鉴权**：是（管理员 JWT）
- **加密模式**：端到端加密

---

## 请求参数

### Path Parameters

| 参数名 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `uuid` | `string` | 是 | 网盘曲目 UUID |

---

## 响应数据

### 成功响应

返回完整 `CloudMusicTrack` 对象。
