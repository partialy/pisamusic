# 删除专属消息记录

管理员硬删除一条发送给用户、Android 设备或 PC 设备的专属消息。删除后该消息不再出现在后台分页列表，也不会再被客户端未读接口拉取；已被客户端展示的消息不提供撤回语义。

- **请求方法**：`DELETE`
- **请求路径**：`/api/admin/messages/:id`
- **需要鉴权**：是（`Authorization: Bearer <AdminToken>`）
- **加密模式**：端到端加密

## 路径参数

| 参数 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | `string` | 是 | 专属消息 ID。 |

## 返回数据

```json
{
  "code": 0,
  "msg": "留言已删除",
  "data": {
    "id": "806ce22e-87bd-4af0-8395-983ad24a1b8c",
    "deleted": true
  },
  "success": true
}
```

## 错误响应

| HTTP 状态 | 说明 |
| :--- | :--- |
| `400` | 消息 ID 为空或格式无效。 |
| `401` | 管理员 Token 缺失、无效或过期。 |
| `404` | 消息不存在，或已被删除。 |
| `500` | 服务端删除失败。 |
