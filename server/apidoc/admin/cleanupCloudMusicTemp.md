# 一键清理临时网盘文件 (管理后台)

根据选择的时间阈值（`0` 全部、`24` 小时前、`72` 小时前），逐曲清理临时曲目及其全部关联七牛云存储对象与数据库记录。

- **请求方法**：`POST`
- **请求路径**：`/api/admin/cloud-music/temp-cleanup`
- **需要鉴权**：是（管理员 JWT）
- **加密模式**：端到端加密

---

## 请求参数

### Request Body (JSON)

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `olderThanHours` | `number` | 是 | 清理时间阈值（小时），可选 `0`（全部）、`24` 或 `72` |

---

## 响应数据

### 成功响应

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "scanned": 3,
    "deleted": 3,
    "failed": []
  },
  "success": true
}
```
