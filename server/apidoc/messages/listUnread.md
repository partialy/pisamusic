# 获取未读专属消息

客户端在启动完成或账号会话变更后读取当前账号和本机设备可见的未读专属消息。消息按创建时间正序返回，客户端按队列依次展示；本接口不改变已读状态。

- **请求方法**：`GET`
- **请求路径**：`/api/messages/unread`
- **需要鉴权**：至少提供有效的 User JWT 或设备消息凭证之一
- **加密模式**：端到端加密

## 请求参数

### Headers

| Header | 必填 | 说明 |
| :--- | :--- | :--- |
| `Authorization: Bearer <UserToken>` | 否 | 有效时纳入账号专属消息；可与设备凭证同时发送。 |
| `x-pm-device-token: <messageToken>` | 否 | 设备上报接口返回的 30 天设备消息凭证，仅纳入该设备专属消息。不得传设备 UUID 代替。 |

至少提供其中一项；两项均缺失或无效时返回 `401`。

### Query Parameters

| 参数名 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `limit` | `number` | 否 | 返回条数，范围 `1-50`，默认 `50`；超出范围会夹取到边界，非整数按默认值处理。 |

## 返回数据

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "items": [
      {
        "id": "806ce22e-87bd-4af0-8395-983ad24a1b8c",
        "targetKind": "user",
        "content": "欢迎使用新功能。",
        "createdAt": 1756780800000
      },
      {
        "id": "d4c3b2a1-1c20-4b80-9e0f-111111111111",
        "targetKind": "android_device",
        "content": "此设备需要重新连接网络。",
        "createdAt": 1756780860000
      }
    ],
    "hasMore": false
  },
  "success": true
}
```

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `items[].id` | `string` | 消息 UUID，用于已读回执。 |
| `items[].targetKind` | `user \| android_device \| desktop_device` | 消息原始接收方类型。 |
| `items[].content` | `string` | 管理员发送的消息正文。 |
| `items[].createdAt` | `number` | 创建时间戳（毫秒）。 |
| `hasMore` | `boolean` | 当前限制下是否仍有未读消息。 |

## 读取与合并规则

- 当请求同时携带有效账号和设备凭证时，返回“该账号消息”与“该设备消息”的并集，不重复返回同一消息。
- 只携带账号时仅返回账号消息；只携带设备凭证时仅返回相应 Android 或桌面设备消息，适用于尚未登录账号的客户端。
- 服务端只返回 `readAt` 仍为空的记录，固定按 `createdAt ASC, id ASC` 排序，最多 50 条。
- 此接口不使用本地长期已读缓存。客户端可以在当前进程用临时已关闭集合避免重复弹窗；网络失败或未成功回执的消息在下次启动仍会再次返回。

## 错误响应

| HTTP 状态 | 说明 |
| :--- | :--- |
| `400` | 参数校验失败。 |
| `401` | 未提供有效 User JWT 和设备消息凭证。 |
| `500` | 服务端读取失败。 |
