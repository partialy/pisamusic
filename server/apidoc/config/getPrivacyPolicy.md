# 获取隐私政策

获取客户端展示的隐私保护指引/隐私政策标题、版本和纯文本正文。

- **请求方法**：`GET`
- **请求路径**：`/api/config/privacy-policy`
- **需要鉴权**：否
- **加密模式**：明文白名单路径

---

## 响应数据

### 成功响应

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "title": "PisaMusic 隐私政策",
    "content": "我们高度重视您的隐私保护...\n\n第二段内容。",
    "version": 1
  },
  "success": true
}
```

### 响应字段说明

| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `title` | `string` | 隐私政策标题 |
| `content` | `string` | 隐私政策纯文本全文，使用 `\\n` 表示换行，客户端按原文显示 |
| `version` | `number` | 当前内容版本，从 `1` 开始；实际内容变化时递增 |

客户端不得将 `content` 当作 HTML 解析；历史 HTML 仅由服务端初始化迁移为纯文本。
