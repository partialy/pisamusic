# 获取隐私政策

获取客户端展示的隐私保护指引/隐私政策标题与正文。

- **请求方法**：`GET`
- **请求路径**：`/api/config/privacy-policy`
- **需要鉴权**：否
- **加密模式**：明文白名单路径

---

## 响应数据

### 成功响应

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "title": "PisaMusic 隐私政策",
    "content": "我们高度重视您的隐私保护..."
  },
  "success": true
}
```

### 响应字段说明

| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `title` | `string` | 隐私政策标题 |
| `content` | `string` | 隐私政策内容全文 |
