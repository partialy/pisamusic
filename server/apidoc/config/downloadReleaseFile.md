# 安装包签名下载入口

统一安装包对外安全下载入口。客户端访问此入口，服务端校验文件状态并生成七牛私有空间临时签名下载 URL，然后执行 302 重定向，避免将私有存储空间直链直接暴露给客户端。

- **请求方法**：`GET`
- **请求路径**：`/api/config/release-files/:id/download`
- **需要鉴权**：否
- **加密模式**：明文白名单路径

---

## 请求参数

### Path Parameters

| 参数名 | 类型 | 必填 | 说明与限制 |
| :--- | :--- | :--- | :--- |
| `id` | `string` | 是 | 统一文件记录 ID（`file_records` 表的主键 ID） |

---

## 响应数据

- **HTTP 302 Found**：重定向到七牛临时签名下载链接（带下载有效期 token）。
- **404 Not Found**（JSON）：安装包记录不存在或状态为已删除（`deleted`）。
- **403 Forbidden**（JSON）：服务处于停机维护状态。
