# 发送手机号验证码

向大陆手机号发送验证码，用于注册、验证码登录或重置密码。短信与邮箱验证码使用同一通知服务。

- **请求方法**：`POST`
- **请求路径**：`/api/auth/phone-code`
- **需要鉴权**：否
- **加密模式**：端到端加密

## 请求参数

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `phone` | `string` | 是 | 11 位大陆手机号 |
| `purpose` | `string` | 是 | `register`、`login` 或 `reset_password` |

验证码有效期及频控规则与邮箱验证码一致。验证码登录时，手机号未注册会在校验成功后自动创建账号。
