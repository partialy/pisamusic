# 服务健康检查

服务端健康检查与探活接口，用于负载均衡、容器探针或网关状态检测。

- **请求方法**：`GET`
- **请求路径**：`/api/health`
- **需要鉴权**：否
- **加密模式**：明文白名单路径

---

## 响应数据

### 成功响应

```json
{
  "msg": "ok",
  "code": 0,
  "data": {
    "status": "up"
  },
  "success": true
}
```

### 响应字段说明

| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `status` | `string` | 服务状态，正常运行为 `up` |
