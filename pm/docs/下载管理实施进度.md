## 实现边界

- HTTP 206 只有验证器、范围及长度一致才追加；200 完整重写；416 或不可信续传有限回退为完整请求。
- 普通失败保留 `.part`，暂停长期保留；主动取消或删除记录时仅清任务独占的合法临时文件。默认仅删记录，保留正式音频、歌词和 LOCAL 索引。
- 绝对路径 LOCAL 单曲播放在准备期间持有短期占用预留；成功发布当前歌曲、失败或取消后释放，删除在同一路径锁内检查预留及当前歌曲。`content://` 导入行为不变。
- 已完成但实际文件存在且无法解析时，菜单提供修复、详情、删除，不提供核心会拒绝的重新下载；真正丢失文件可沿用原记录重下。
- 未新增常驻前台下载服务；只承诺进程存活时继续执行，进程退出后由用户手动恢复。

## 待老大真机验收

当前无设备连接，以下不得视为通过：

1. 双页横滑、系统边缘返回、长按编辑、搜索外勾选、旋转与深浅主题。
2. 大文件暂停后字节停止增长、206 恢复、200/416 回退、断网与过期链接、进程被杀后的恢复。
3. 原目录不可用、账号失权、不支持原音质、存储空间不足等异常。
4. 单条/多选/清除全部，播放或准备中文件保护、共享音频与歌词引用、删除失败保留记录。
5. LOCAL 播放保留原队列、一起听禁止本地播放、详情字段与点击复制、已下载目录保留文件。
