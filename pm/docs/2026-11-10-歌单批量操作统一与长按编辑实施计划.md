## 1. 目标和最终用户交互

1. 在“我的 → 我的收藏 → 详情 → 批量操作”以及“我的 → 本地歌单 → 详情 → 批量操作”中，将底部第三格统一改为“操作”，和在线歌单对齐，保留“全选 / 反选 / 操作”三格。
2. 点击“操作”展示既有 ActionMenuBottomSheet，三个菜单项按顺序为“删除 / 下载 / 添加到”。删除为危险色，另外两项使用默认主题色；头部继续通过 SongInfoHeaderBinder 展示第一首被选中歌曲的信息。
3. “删除”仅将歌曲移出当前所属收藏或本地歌单，不能删除音频文件、下载任务、其他歌单中的记录或播放列表；弹窗按上下文写“取消收藏”或“从歌单移除”，复用既有 PmMinimalDialog。
4. 下载仅处理非 LOCAL 且 playable=true 的选中歌曲；LOCAL 自动过滤，全部都是 LOCAL 时保留“下载”菜单并提示本地歌曲不支持在线下载。不可播放条目视为本次未处理，保留勾选。
5. “添加到”保持当前播放队列、其他已有本地歌单和新建本地歌单三种目标；允许 LOCAL，保留不可播放歌曲元数据进入本地歌单，但加入播放队列时沿用现有 playable 校验。从本地歌单 A 发起时目标 Sheet 不展示 A。
6. 下载和“添加到”仅解除实际成功或“已存在/已在队列”歌曲的勾选；失败或未处理项留选。删除成功后由权威 Flow 刷新列表、淘汰已不存在歌曲的选择。
7. 四个歌单详情页面——我的收藏、本地歌单、KG 在线歌单、WY 在线歌单——长按歌曲行主体，立即进入该歌单现有的批量操作 Activity，自动勾选并定位被长按的歌曲。独立歌曲搜索页不增加长按。点按与行内收藏/下载/更多图标行为保持原样。
8. 长按遵循系统触觉反馈设置；一次手势只触发一次跳转。普通“批量操作”按钮仍从列表顶部、默认不选中进入。
9. 长按的歌曲在在线歌单尚未完全分页加载时，仍先显示其初始选中状态；直到权威完整列表确认不存在，才移除该选择；若加载失败允许重试。
10. 保持所有已有搜索、分页、排序、播放与返回行为；从批量页返回详情，不自动播放或修改原在线歌单。

## 4. 推荐架构与实现顺序

### 4.1 共用的操作协调层

建议新增 ui/mine/PlaylistBatchActionCoordinator.kt（或职责相同的文件），收敛两个本地批量页与在线批量页的“展示操作 Sheet / 调起下载 / 调起添加到 / 汇总结果”共同流程。不将本地/收藏删除业务硬编码到在线 Activity。三个 Activity 只提供权威源歌曲、选中键、busy 更新、上下文删除回调等委托。

- 用快照解析选中歌曲：resolveSelectedPlaylistSongs(sourceSongs, selectedKeys)；绝不只用歌曲 ID 匹配。
- 抽公共方法时保留在线专用“收藏”菜单，在线为“下载 / 收藏 / 添加到”，本地/收藏为“删除 / 下载 / 添加到”；在线歌单不增加删除原歌单歌曲的操作。
- 共用 Sheet 的 head binder 与 result callbacks；当点击“添加到”后由 AddToPlaylistBottomSheet 使用其现有异步结果。
- 防重依赖统一 busy 状态和一次性完成回调，不在 Sheet dismiss 与任务成功两条路径重复释放 busy/提示。
- 所有与 Activity 绑定的 Dialog、监听、Job 在宿主销毁后停止交互；失败结果不吞异常后误报成功。

### 4.2 两个本地批量 Activity、布局和状态

- 把 activity_local_playlist_song_management.xml 的第三格从 deleteAction 调整为 operationAction：ic_more_24、正常颜色、“操作”文字，沿用 actionSurface、64dp 行高、insets、三个等权区域。
- LovedSongsManagementActivity 和 LocalPlaylistSongManagementActivity 保留各自来源 Flow、搜索与分页逻辑，删掉直接绑定第三格删除的监听，改为 showOperations()；实际删除复用原 PmMinimalDialog 和原调用。
- 两个 Activity 改继承 BaseDownloadActivity（其基类是 BaseActivity），或以等效、低侵入委托取得下载入口，确保依赖注入、原生生命周期均兼容。
- 增加 savedInstanceState 保存 search query 和 selectedKeys；初始 EXTRA_INITIAL_SELECTED_SONG_KEY 只有首次创建、没有恢复状态时应用一次；选中以权威源为准合并。
- 数据流到达后 retainAll 有效键；操作执行前再次取权威源和选中交集；删除完成只清理确实已移除项，不应因为返回 Boolean 就误报全量删除成功。
- 新增/调整 strings，避免影响歌单管理页或下载管理页对旧字符串的引用。

### 4.3 长按详情页并预选

- ui/widget/SongListItemBinder.kt：SongListItemActions 增加可选 onLongClick: ((SongInfo) -> Unit)?；在每次 bind 时给 root 设置/清理 OnLongClickListener，避免 RecyclerView 回收旧监听。仅在 enabled 且提供回调时启用；其他按钮既有 OnClickListener 不改变。
- ui/playlistdetail/PlaylistDetailContentAdapter.kt：构造参数增加可选 onSongLongClick；向 SongListItemBinder 透传；原生播放列表样式、收藏、更多等正常不变。
- 四个详情 Activity 的 createContentAdapter() 传自己的长按处理；使用系统标准长按反馈，单次长按加快速跳转保护；保留顶部原批量按钮入口。
- LovedSongsManagementActivity.start、LocalPlaylistSongManagementActivity.start、OnlinePlaylistBatchActivity.start 新增可选 initialSelectedSongKey 或原始 SongInfo 的 type+id 组合；默认 null 保持原有调用兼容。不把整份歌曲对象重复塞进 Intent。
- 在线启动仍传已有轻量 sessionToken、source、playlistId、total、title，以及独立的 initialSelectedKey；支持 Android 重建恢复。
- 为长按预选添加“初次定位”一次性标志。sourceSongs/filter 完成后按键找到目标位置，适当扩张现有按 40 首逐段呈现的窗口，再在 RecyclerView 本轮布局完成时 scrollToPositionWithOffset；不触发播放、不改变排序。只定位首次，后续用户主动滚动/搜索不自动抢焦点。
- 如果目标歌曲不在当前查询结果中，不清空查询或强制定位；长按原详情入口一般查询为空。重复回调、旋转后的锚点逻辑需避免二次跳转/跳动。

### 4.4 在线歌单的初选与分页竞态

- 在线 Activity 读取 EXTRA_INITIAL_SELECTED_SONG_KEY，只在 savedInstanceState 不含恢复选择时注入 selectedKeys。
- 将“初选待权威验证”与普通选择状态区分，或者最少确保在 complete=false / failed=true 的分页更新中不执行按当前不完整歌曲集合 retainAll。
- 初始 SessionStore 已包含长按歌曲时优先渲染并自动选中；SessionStore 失效/进程重启时保留单独的初选键，等 loader 按歌单 ID 找到后补勾选并定位。
- 仅在 complete=true 时对 selectedKeys 做全量有效键校验；确实不在歌单中时取消自动勾选，不允许对陈旧曲目执行操作；加载失败保留选择意图但只能操作当前实际可解析、仍存在的选中歌曲，允许点击状态重试。
- 防止源歌曲列表变更、过滤 Job 的后到结果、自动定位任务早于 RecyclerView submit 完成造成错误定位；所有待执行操作先解析最新权威快照。

### 4.5 混合音源下载调度（重点）

建议新增 ui/mine/PlaylistBatchDownloadCoordinator.kt（或 ui/download/ 同职责文件）；共享在线批量原有逻辑与两个新入口。保留 BaseDownloadActivity.startSongsDownloadFlow 的现有公共行为，抽取可复用、可取消的“单组选择音质并入队”底层方法，供单次旧入口和多组入口调用；必要时增加结果提示抑制开关，但不改变其他调用方默认提示。

调度顺序：
1. 从当前来源权威快照解析选中，基于 SongType+SongId 去重，保留歌单原顺序。
2. 分离 LOCAL（过滤计数）与 playable=false、无效 id（未处理/失败计数）；实际可下载数量按剩余有效歌曲计算。若没有可下载歌曲，按情形只显示一次明确提示。
3. 对实际可下载歌曲按 SongType 分组，组顺序采用完整选中歌曲中首次出现的类型次序；每组保持原歌单相对顺序，KG/WY/KW/CLOUD 逐组单独选音质，绝不复用上一组 choice。
4. 如果有效总数 >100，统一显示一次超量确认。确认取消则不处理任何组、保持选择。
5. 依次显示组内音质选择器，使用现有 MusicQualityAccessPolicy 权限标识，合法选择后调 DownloadQueueCoordinator.enqueue。音质选择返回 null、用户进入登录/反馈或退出 Activity，均停止后续组。
6. 每组只根据 DownloadEnqueueSummary.enqueuedKeys 与 skippedKeys 清除“已处理”的选择；failedKeys 和未开始组的键保留。组内失败不应自动阻断后续组，除非用户主动取消或生命周期结束。
7. 维护总成功数、已有/跳过数、失败数、LOCAL 过滤数和不可播放数量。正常结束（含中途取消已有结果）只给一次最终 PmMessage；不同时展示各组 BaseDownloadActivity 提示。
8. 明确成功含义为已加入下载队列，不表示物理下载完成。退出页面后不再拉起音质 Dialog，已入队任务仍由进程级下载协调器管理。
9. 宿主 lifecycleScope 取消时及时关掉尚未提交的选择器；已提交的任务不回滚。异步回调返回时若 Activity 已销毁则不能再访问 binding 或弹窗。
10. 复用登录/VIP 权限策略，混合输入绝不对某一音源使用其他音源的音质选项；对 cloud 默认档位亦不特殊假定为 KG/WY。

### 4.6 添加到、删除、计数的精确语义

- AddToPlaylistBottomSheet.show() 新增可选 excludeLocalPlaylistId: String? = null，仅本地歌单批量页传当前 playlistId；默认行为不变。过滤目标时基于 id 且 type=LOCAL，队列和新建入口始终保留。
- 添加到播放队列沿用 appendSongsLazyWithResult，不自动播放、保持顺序并按 type+id 去重。不可播放歌曲遵循底层 result.failed，不清除其选择。
- 添加到现有本地歌单与新建本地歌单沿用现有存储事务和同步 outbox，不另建 DB 或添加新接口；已有项视为跳过，成功/已存在都解除勾选，失败保留。
- 收藏删除：执行前以 loveListFlow 当前快照求交集，调用 removeSongsFromLoveList；从更新后的权威列表对照确定成功移除键。
- 本地歌单删除：执行前以 getLocalPlaylistSongs 最新快照按 type+id 求交集，调用 removeSongsFromLocalPlaylistByIdentity，再从更新后的歌单歌曲列表确认结果；不动音频文件、其他歌单与当前播放队列。
- 删除前仍保留 PmMinimalDialog 危险色确认，不因统一操作菜单而省略确认；无选中、busy 或已被移除的项不可提交。
- 大于 100 首添加到目标的确认沿用 AddToPlaylistBottomSheet 内现有行为；结果计数以回调为准，取消不清空勾选。

## 7. 验收矩阵（供用户手动验收）

| 场景 | 预期 |
|---|---|
| 收藏批量页 | 底部全选/反选/操作；操作 Sheet 为删除/下载/添加到 |
| 本地歌单批量页 | 同上，删除仅移除当前歌单关系 |
| 在线 KG/WY 批量页 | 保持下载/收藏/添加到，无“删除在线歌曲” |
| 四种详情页长按歌曲主体 | 直接打开正确批量页，初始已选 1 首并定位原歌曲 |
| 四种详情页点击普通歌曲 | 正常播放；收藏/下载/更多图标功能照旧 |
| 不同音源相同 id | 长按、删除、下载、添加到都精确按 type+id 处理 |
| 仅 LOCAL | 下载仍可见，点击单次提示，不入队 |
| KG/WY/KW/CLOUD 混选 | 按首次出现顺序分组、每组选择匹配音质，全部结束只汇总一次 |
| >100 首但过滤后 <=100 | 不弹超大批量确认 |
| >100 有效首 | 仅开始前确认一次，再逐组选择音质 |
| 第 2 组取消 | 第 1 组已入队保留，后面不弹音质，未处理项留选 |
| 中途退出或旋转 | 未提交任务不继续弹窗；已入队任务不回滚；重建后选择与查询正确恢复 |
| LOCAL + 远程歌曲混选 | 只下载有效远程；正确汇总 LOCAL 数量 |
| 不可播放歌曲 | 下载跳过；本地歌单可存元数据；队列遵循已有 playable 校验 |
| 添加到原本地歌单 | 目标列表排除原歌单，其他目标不受影响 |
| 添加到队列 | 尾部追加、同来源同 ID 去重、不自动播放 |
| 收藏删除 | 二次确认、成功后 Flow 更新；其他本地歌单与文件不变 |
| 本地歌单删除 | 只移除当前歌单，精确到来源+ID |
| 在线歌单未完全加载 | 被长按歌曲保留初始选择；完成全量核验后再决定是否淘汰 |
| 在线歌单加载失败 | 可重试；不会把未加载到的歌曲错误视为已删除 |
| 搜索、全选、反选 | 作用于当前过滤全集且保留过滤外已有选择 |
| 数据刷新/失败/双击 | 权威源校验、防重复提交，不出现虚假的全成功或错误清空选择 |
| 普通批量按钮入口 | 从顶部进入，默认无选择；与长按入口互不影响 |
