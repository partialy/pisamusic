# Android 版本发布简述

## v2.8.9（2026-11-26）

### 后台发布说明

- 歌曲下载启用服务端配额。游客按设备计数，登录账号跨设备共享额度，会员档位和单独配置按后台规则生效。
- 批量下载仅核算实际新增任务。额度不足时显示周期余量和额外次数，游客可从提示直接登录。
- 公告支持确认倒计时与快捷跳转，侧栏支持更多菜单布局。内嵌网页加载失败时可在当前页重试。
- 新增伴奏歌词及独立显示设置。

### 版本记录与验证

- 版本由 v2.8.8（536）升级至 v2.8.9（537）。基线为 dev 的 `b3f8468d`，music-service 试运行改动在独立工作树继续开发。
- 四档配额依赖兼容的 Server 版本。交付前核对下载扣减与拒绝逻辑，并验证正式安装包能覆盖更新。
- 本次沿用既有音质策略，发布前保留真机验证与生产上线状态记录。

## v2.8.8（2026-11-25）

### 后台发布说明

- 侧栏新增公告、意见反馈、检查更新和外观切换快捷入口，支持横栏与九宫格动态菜单及红点提醒。应用内网页可随页面更新标题，也支持全屏展示。
- 侧栏的「三方账号管理」统一管理酷狗和网易云账号，支持校验登录状态、手动刷新和可选的自动刷新。可在账号页直接进入歌单导入。
- 播放和下载设置可分别为酷狗、网易云设置默认音质。选择固定下载音质后，有权限的歌曲可直接入队。
- 「我的 → 歌单」顶部固定显示搜索、批量管理和导入入口。歌单收藏的操作集中在三点菜单中。
- 「意见反馈」新增反馈记录，可查看处理状态、反馈详情及图片附件。
- 修复云盘投稿时 LRC 文件灰选，以及部分正常封面和临时下载被校验拦截的问题。支持投稿 LRC、TXT、KRC、YRC 歌词，并播放 KRC/YRC 逐字歌词。

### 版本记录与验证

- 版本号由 v2.8.7（versionCode 535）升级为 v2.8.8（versionCode 536）。
- 整理范围为上一版本 `babfca63` 之后至 `325dd340` 的手机端改动，覆盖涉及 `pm/` 的 18 条提交。
- PM 云盘投稿修复已通过 Debug Kotlin 编译。服务端错后缀封面、下载长度和 KRC 解码已通过模拟验证，本次版本升级校验 Gradle 生成的版本信息。真机交互和七牛实传待验收。
- 动态侧栏、反馈记录和云盘投稿修复涉及配套 Server 变更，发布时需核对服务端部署版本。

## v2.8.7（2026-11-24）

### 后台发布说明

- 歌单管理更方便：「我的 → 歌单」新增批量管理与导入快捷入口，支持长按歌单进入管理并自动勾选、定位；管理页支持关键词搜索、全部 / KG / WY 来源筛选、全选与反选，以及二次确认批量删除，切换筛选时保留已有选择。
- 键盘交互优化：统一调整歌单导入、歌单管理、收藏管理、本地音乐编辑、下载管理等页面的键盘避让，输入或搜索时底部操作栏保持可见。
- 意见反馈修复：修复提交时提示「missing encryption header」的问题，补齐系统加密请求头与响应解密，兼容图片附件上传。
- 网络通信更安全：隔离系统账号与第三方音乐请求，避免向音乐网关附带系统账号凭证；关闭正式版网络明细日志，并隐藏调试日志中的敏感请求头。

### 版本记录与验证

- 版本号由 v2.8.6（versionCode 534）升级为 v2.8.7（versionCode 535）。
- 整理范围：上一版本提交 `f1108c99`（v2.8.6）之后至 `6c5356e5` 的手机端（pm）全部功能与修复改动，共 4 条提交。
- 上述功能与修复已通过 Debug Kotlin 编译及差异检查；本次升级仅调整版本号与发行说明，校验 Gradle 配置与生成的版本信息，不重复执行完整编译或测试。歌单管理、键盘避让、反馈提交及网络交互仍需真机手动验收。

## v2.8.6（2026-11-23）

### 后台发布说明

- 三方歌单导入更顺手：新增独立「导入歌单」页面，支持本地缓存秒开、手动刷新、关键词搜索、全部 / KG / WY 来源筛选、全选与反选，以及已导入歌单自动标记跳过；清除或切换三方账号时同步清理对应平台歌单缓存。
