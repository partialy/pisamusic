# Android 版本发布简述

## v2.8.4（2026-11-21）

### 后台发布说明

- 账号同步更稳健：优化多设备收藏与歌单同步逻辑，修复切换账号重登后误覆盖与时钟冲突问题，保障云端数据一致性。
- 界面显示修复：修复歌单收藏等三列网格封面偶发被纵向拉高变形的问题，统一保持正方形比例展示。
- 弹窗动效统一：统一全端底部弹窗样式与纯平移滑入/收起动画，整体交互过渡更顺滑自然。

### 版本记录与验证

- 版本号由 v2.8.3（versionCode 531）升级为 v2.8.4（versionCode 532）。
- 整理范围：上一版本提交 `0a2143e`（v2.8.3）之后至 `84c77ba` 的手机端（pm）全部功能与界面改动。

## v2.8.3（2026-11-20）

### 后台发布说明

- 全新歌词特效与动画：新增六款歌词视觉特效与独立配色方案，支持自定义歌词样式参数、颜色管理与渲染帧率；歌词滚动升级为更顺滑的弹性动画，修复切行与折行跳动。
- 启动更快更轻盈：优化应用启动加载流程，启动页换上全新音柱动效，打开应用更迅速流畅。
- 歌单与账号更完善：支持自建歌单上传与恢复封面，优化多账号数据隔离与跨端本地歌曲识别。
- 新增下载额度提醒：下载歌曲前自动检查可用次数，额度不足时给出清晰提示。
- 交互细节优化：支持主页侧边栏左滑收起，修复歌单详情页顶部状态栏遮挡，优化弹窗与加载提示体验。

### 版本记录与验证

- 版本号由 v2.8.2（versionCode 530）升级为 v2.8.3（versionCode 531）。
- 整理范围：上一版本提交 `4349dff`（v2.8.2）之后至 `e0f815d` 的手机端（pm）全部功能与界面改动。

## v2.8.2（2026-11-13）

### 后台发布说明

- 播放器封面页升级：新增半露取色 CD、整盘旋转及切歌合拢展开动画。
- 优化切歌时封面与背景的加载衔接，新增适配深浅色主题的默认封面。
- 优化收藏与歌单的账号同步、收藏时间排序及失败重试，提升多设备同步稳定性。
- 云盘歌曲支持一起听，修复歌曲时长与歌词格式识别问题。
- 完善本地歌曲长按批量管理、全选与反选，修复下载音频标签、封面及来源信息写入。

### 版本记录与验证

- 版本号由 v2.8.1（versionCode 529）升级为 v2.8.2（versionCode 530）。

## v2.8.1（2026-11-10）

- 歌单详情批量编辑优化：我的收藏、本地歌单、KG 与 WY 在线歌单均支持长按歌曲进入批量操作，并自动勾选、定位目标歌曲。
- 收藏与本地歌单批量操作统一为“删除 / 下载 / 添加到”，保留确认与源歌单关系隔离。
- 混合音源批量下载按来源选择音质，自动过滤不可下载条目并汇总结果；优化添加到目标与页面状态恢复。
- 版本号由 v2.8.0（versionCode 528）升级为 v2.8.1（versionCode 529）。
- 新功能已通过 Debug Kotlin 编译与针对性单元测试，真机交互仍需手动验收。

## v2.8.0（2026-11-09）

- 播放界面焕新：新增封面与完整歌词双页切换、黑胶展示和三行逐字歌词，优化歌词高亮、滚动与切页手势。
- 动态背景升级：全新流光效果，支持参数调整、实时预览和恢复默认，优化静态回退与动画资源管理。
- 下载管理升级：新增“下载中 / 已完成”双页、进度展示、暂停与恢复、断点续传；支持已完成搜索、多选、歌曲详情、本地播放及批量清理。
- 下载更稳定：完善续传校验、失败重试和音质一致性，修复过期任务回调与文件清理并发问题，保护正在播放及共享引用的文件。
- 一起听体验优化：修复房主更换歌单后的队列同步，优化单人房间头像与播放页布局。
- 封面与交互优化：统一歌曲、歌单详情高清封面与加载回退，改善播放页标题布局，新增搜索及首页推荐单曲实际起播成功提示。
