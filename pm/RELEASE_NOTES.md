# Android 版本发布简述

## v2.8.0（2026-11-09）

- 播放界面焕新：新增封面与完整歌词双页切换、黑胶展示和三行逐字歌词，优化歌词高亮、滚动与切页手势。
- 动态背景升级：全新流光效果，支持参数调整、实时预览和恢复默认，优化静态回退与动画资源管理。
- 下载管理升级：新增“下载中 / 已完成”双页、进度展示、暂停与恢复、断点续传；支持已完成搜索、多选、歌曲详情、本地播放及批量清理。
- 下载更稳定：完善续传校验、失败重试和音质一致性，修复过期任务回调与文件清理并发问题，保护正在播放及共享引用的文件。
- 一起听体验优化：修复房主更换歌单后的队列同步，优化单人房间头像与播放页布局。
- 封面与交互优化：统一歌曲、歌单详情高清封面与加载回退，改善播放页标题布局，新增搜索及首页推荐单曲实际起播成功提示。
