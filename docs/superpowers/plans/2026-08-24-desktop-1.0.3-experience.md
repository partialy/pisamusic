# Desktop 1.0.3 Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将桌面端“关于”页嵌入设置页、重构音乐详情/接收分享页、为首页及更多歌曲页补齐统一歌曲菜单，并发布 1.0.3 Windows 安装包。

**Architecture:** 设置页以 query 驱动 Tab，所有“关于”入口统一收敛到 `/setting?tab=about`；详情页继续复用 `/media/detail` 和现有分享 DTO/IPC，仅替换展示结构。歌曲操作继续复用 `ContextMenu.vue` 和统一播放命令层，列表组件只负责提供歌曲、触发坐标及“添加到歌单”弹窗。

**Tech Stack:** Electron 37、Vue 3.5、TypeScript 5.8、Vue Router 4.5、Pinia 3、Naive UI 2.42、lucide-vue-next、SCSS、electron-builder 26。

## Global Constraints

- 仅修改 `yixi/` 桌面端与项目文档，不处理 `pm/app/build.gradle.kts` 的现有用户改动。
- 不新增独立关于页；设置页“关于”Tab、右上角“设置 → 关于”和旧 `/about` 地址必须进入同一位置。
- 所有播放行为必须经 `src/listenTogether/playbackCommands.ts`，不得直接调用音频 Store 的播放/队列修改方法。
- 详情路由继续使用 `/media/detail`，query 仅携带现有白名单 canonical payload 或分享 UUID。
- 不新增第三方依赖；菜单图标复用项目图标与现有 `lucide-vue-next`。
- 按用户要求不运行测试套件；仅运行必要的类型/构建检查和最终 Windows 打包。
- Git 提交信息使用中文，并按功能阶段拆分提交。

## File Structure

- `yixi/src/views/setting.vue`：设置 Tab 容器；解析并同步 `tab` query，新增“关于”Tab。
- `yixi/src/components/setting/about/AboutSetting.vue`：由原关于页迁入的可嵌入内容组件，保留版本、更新、协议、隐私与反馈能力。
- `yixi/src/components/setting/index.ts`：统一导出 `AboutSetting`。
- `yixi/src/components/Header.vue`：右上角“关于”统一导航到设置页 About Tab。
- `yixi/src/router/index.ts`：旧 `/about` 路由重定向到 `/setting?tab=about`。
- `yixi/src/views/media/MediaDetailView.vue`：重构歌曲/歌单详情与接收分享展示，移除多余返回按钮。
- `yixi/src/components/common/ContextMenu.vue`：支持首页场景隐藏下载项，并将歌曲菜单排序/文案对齐需求。
- `yixi/src/components/playList/KGRecommendSong.vue`：为歌曲行暴露右键与“更多”点击事件。
- `yixi/src/components/home/HomeSongGrid.vue`：接入统一歌曲菜单和“添加到歌单”弹窗。
- `yixi/src/views/recommend/RecommendSongPage.vue`：为更多歌曲页接入右键与“更多”菜单。
- `yixi/package.json`、`yixi/package-lock.json`：桌面端版本升级至 `1.0.3`。
- `AGENTS.md`、`yixi/AGENTS.md`：同步关于页入口、详情页和首页歌曲菜单的职责说明。
